## Specification Workflow

Each feature follows a 5-phase process:

1. **instructions.md** - Initial requirements and user stories
2. **requirements.md** - Structured functional/non-functional requirements (requires approval)
3. **design.md** - Technical design and implementation strategy (requires approval)
4. **plan.md** - Implementation roadmap and progress tracking (requires approval)
5. **Implementation** - Execute the plan (requires approval)

**Note**: User approval is required before proceeding between phases.
